Social cards

Keybridge IT · Social cards

Each card renders at two sizes. OG 1200×630 is the link-preview image (set as og:image; used automatically by messaging apps, Facebook, X and LinkedIn link previews). Square 1280×1280 is for native LinkedIn / Instagram image posts you upload by hand.

Show:
Paths: cards load from BASE below; set to /socials/ for your live site. Change it if you deploy this folder somewhere else (use './' for opening straight off disk).
Export: open any card and use the on-canvas PNG 2× button, or click a PNG ⬇ link below to auto-download. Toggle Square / OG on the card itself too.
Add / reorder cards: edit the CARDS array in the script below; order here is export order.
Logo: replace keybridge-logo.svg in this folder with the real brand mark (keep the filename).
